# LiquidGlass validation (simulator + device)

## Snapshot matrix
- Light / Dark
- Reduce Transparency ON/OFF
- Increase Contrast ON/OFF
- Dynamic Type: default and XXL

## Performance checks
- Scroll a list with glass header and check FPS
- Long-running screen (5–10 min) to detect thermal throttling signs

## Practical note
Simulators approximate materials but may not match device.
Always validate on at least one physical iPhone + one physical Watch.
