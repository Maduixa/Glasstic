# Privacy & compliance for on-device ML in health apps

## Principles
- Process health-related signals on-device by default.
- If you transmit derived insights, disclose clearly and secure transport.
- Avoid “medical advice” language unless you have regulatory clearance.

## UX recommendations
- Explain in-product what the model does and what it does NOT do.
- Allow user to delete derived data and reset model personalization (if any).
