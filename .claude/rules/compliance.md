# Compliance rules (Health + AI)

- Avoid claims that imply diagnosis, treatment, or medical measurement beyond device capabilities.
- Include clear permission rationale strings; do not misrepresent data usage.
- Keep a review notes template ready explaining:
  - what HealthKit types are accessed and why
  - that processing is on-device (if true)
  - that user can revoke permissions at any time
